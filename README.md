## Anotações 

#### O que é Back-end
É o motor invisível que processa os dados e gerencia e a lógica 
* Ele funciona nos bastidores (no servidor) e é responsável por garantir a segurança, velocidade e o armazenamento das informações.


![img](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQQFAVEfFLIsYuAuEqZm9ukgb8P1IpjPLdNaqENkeZ_fg&s=10)

### O que é API
API (Interface de Programação de Aplicações) funciona como uma ponte ou um "garçom" entre o Front-end e o Back-end
* Ela é o mensageiro essencial que leva o pedido do usuário até o sistema e devolve a resposta, garantindo que o Front-end não precise falar diretamente com o banco de dados

### O que é Front-end
É a interface visual e interativa de um software, ou seja, a parte com a qual o usuário interage diretamente
* Focada na experiência (UX) e interface (UI) do usuário, ela roda no navegador e representa a "ponta visível do iceberg"

[img](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcSLyRbmjl0b5OnlN5hXqm5DH6oA_hLKeGPGJIA22iVm4ICugOpvS-obdog&s=10)

### Pacotes
No ecossistema de desenvolvimento, um pacote é um bloco de código reutilizável escrito por outros desenvolvedores para resolver problemas comuns
* Eles permitem que você adicione funcionalidades prontas ao seu projeto sem precisar "reinventar a roda", economizando tempo e aumentando a segurança

![img](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTzyGnn5lnvVAogm7C1ml-qrgHBS-zl1Vh_b3RnisLszkRmHVhiAasaPPym&s=10)

### Comandos
Para gerenciar um projeto e seus pacotes, utilizamos comandos específicos via terminal
* Os principais citados nas fontes para iniciar um motor de Back-end incluem

```
* --- npm i (instala o pacote sugerido)
```

```
* --- npx (Executa o pacote que instalou)
```

```
* --- import chalk from 'chalk';
console.log(chalk.blue('Olá mundo!'));
```

```
* --- nodemon (Sua pasta que quer Executar)
```
